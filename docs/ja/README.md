# FES PML Macro ドキュメント

## はじめに

### 動作環境

マクロを使用するには **AVEVA E3D Design 3.1.10 以降 または 4.3.0 (UE 4.0.0) 以降** を推奨します。

### インストール

マクロのセットアップは以下の手順で行います。

1. [Releases](https://auth.fes-hd.jp/releases) ページから最新バージョンをダウンロードします（ログインが必要です）。
2. ZIPファイルの中身を解凍します。
3. `PMLLIB` 環境変数に、解凍したフォルダ内の `pmllib` ディレクトリのパスを設定します。
4. `CAF_UIC_PATH` 環境変数に、解凍したフォルダ内の `cafuic` ディレクトリのパスを設定します。

### 認証

マクロを使用するには、PCにアクセストークンを設定する必要があります。詳細は [PMLAuth](https://auth.fes-hd.jp) ライセンス認証サーバーのページを参照してください（ログインが必要です）。
